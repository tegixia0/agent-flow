# 五阶段开发流程（入口规则）

当用户说"走流程""改造""/flow""下一步""通过""通过 1,3""驳回 2""回到 N""流程状态"，或给出新需求时：

1. 使用技能 **flow-orchestrator**，只读取它的 SKILL.md；阶段技能由编排器按需读取。
2. 新建模式：00 → 01 → 02 → 03 → 04 → 05。存量模式（在现有代码上改）：00 → 01 → **01b 影响定位** → 04 → 05（02、03 为可选）。交接文件都放在 `docs/flow/`。
3. **每轮最多推进一个阶段**，阶段结束后必须停下等待确认。只有用户明确说"通过"（或"通过 n"）时，才能记为已批准。
4. 阶段 1、1b、2、3 只能写 `docs/flow/`，不能修改业务代码。
5. 下一阶段只读取交接文件，不要回看聊天记录。
