# 01 需求分析：按标签筛选（TODO Lens v0.2）

## 一句话目标
在 TODO 列表中按关键字（标签）筛选，只看关心的那一类。

## 用户故事
- US-1 作为开发者，我想只看 FIXME，以便优先处理问题。
- US-2 作为开发者，我想随时知道当前处于哪个筛选，以免误以为其他条目丢了。

## 范围
**范围内**：标题栏的筛选按钮，以及 QuickPick 选项（全部 + 每个关键字）；按筛选显示列表；视图描述显示当前筛选；状态栏显示筛选后数量；筛选在重启后保留。
**范围外**：同时选择多个标签；按文本搜索；按文件或目录筛选。

## 验收标准
| 编号 | 关联故事 | 标准 |
|---|---|---|
| AC-1 | US-1 | 视图标题栏有筛选按钮；点击后弹出 QuickPick，选项为"全部"加上 `todoLens.keywords` 中的每一项 |
| AC-2 | US-1 | 选中标签 X 后，列表只显示 tag 为 X 的条目；没有匹配条目的文件不显示；文件后面的计数是筛选后的数量 |
| AC-3 | US-2 | 筛选生效时，视图标题旁显示"筛选：X"；选择"全部"后清除 |
| AC-4 | US-2 | 状态栏显示"筛选后数量/总数"，例如 `3/10` |
| AC-5 | US-1 | 重启 VS Code 后，筛选状态保持不变 |

## 约束
- 不新增运行时依赖；与 v0.1 的行为兼容（默认不筛选）
